# Codeswithscissors Tap

## How do I install these formulae?

`brew install codeswithscissors/tap/<formula>`

Or `brew tap codeswithscissors/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "codeswithscissors/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
